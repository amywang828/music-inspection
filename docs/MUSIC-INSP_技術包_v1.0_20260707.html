3. 資料庫 Schema（Cloudflare D1）

records（點檢記錄）

CREATE TABLE records (
  id          TEXT PRIMARY KEY,
  -- 格式: {course}_{yyyyMMddHHmmss}_{random4}
  -- 例:   n1_20260707143022_a1b2

  store       TEXT NOT NULL,     -- 店名（對應 stores.name）
  staff       TEXT NOT NULL,     -- 點檢人員姓名
  dept        TEXT,              -- 部別代號（n1/n2/.../gp）
  course      TEXT NOT NULL,     -- 課別代號（n1/n2/.../gp）
  date        TEXT NOT NULL,     -- 點檢日期 YYYY-MM-DD
  answers     TEXT,              -- JSON: {"q1":{"v":"Y","x":""},...}
  nm_reason   TEXT,              -- 未通過原因
  pass_all    INTEGER DEFAULT 0, -- 1=全通過, 0=有未通過
  pass_count  INTEGER DEFAULT 0, -- 通過題數
  total       INTEGER DEFAULT 0, -- 題目總數
  edit_log    TEXT DEFAULT '[]', -- JSON: [{editor,time}]
  created_at  INTEGER            -- Unix timestamp (ms)
);

stores（店舖主檔）

CREATE TABLE stores (
  id          INTEGER PRIMARY KEY AUTOINCREMENT,
  course      TEXT NOT NULL,
  name        TEXT NOT NULL,
  type        TEXT DEFAULT 'M',  -- 店型
  grp         TEXT DEFAULT '',   -- 群組
  last_date   TEXT,              -- 最後點檢日期 YYYY-MM-DD
  created_at  INTEGER,
  UNIQUE(course, name)           -- 同課別不重複店名
);

staff（人員名單）

CREATE TABLE staff (
  id          INTEGER PRIMARY KEY AUTOINCREMENT,
  course      TEXT NOT NULL,
  name        TEXT NOT NULL,
  created_at  INTEGER,
  UNIQUE(course, name)
);

4.1 POST /api/auth

透過 GCP Cloud Run 代理呼叫 FME CheckUserId API 驗證員工帳號。

⚠️ 速率限制每 IP 每分鐘最多 10 次。超過回傳 429。

Request

Content-Type: application/json

{
  "USER_ID": "abc12345",
  "PSW": "password"
}

Response（轉發 FME 回傳）

// 成功
{ "MSG": "Login Success", "CODE": "0" }

// 失敗
{ "MSG": "帳號或密碼錯誤", "CODE": "1" }

// 速率限制
{ "MSG": "429 請求過於頻繁，請稍後再試" }  // HTTP 429

GET /api/records

Query Param型別說明

POST /api/records

ℹ️ 同月同店防重複同課別+店舖+月份已存在時回傳 HTTP 409 {"error":"同月同店已有記錄","duplicate":true}。

{
  "id": "n1_20260707143022_a1b2",  // 必填
  "store": "店名",                  // 必填
  "staff": "點檢人員",              // 必填
  "dept": "n1",
  "course": "n1",                  // 必填
  "date": "2026-07-07",            // 必填

  "nmReason": "",
  "passAll": true,
  "passCount": 10,
  "total": 10

// Side effects:
// 1. UPDATE stores SET last_date = date
// 2. 非同步 syncToSheets({ action: 'insert', record })

// Side effects: syncToSheets({ action: 'update' })

// Response (成功)

5. 驗證流程

前端登入表單 │ POST /api/auth { USER_ID, PSW } ▼ Cloudflare Worker /api/auth │ 1. 速率限制：10次/分/IP（Map-based，重啟失效） │ 2. POST https://music-inspect-403438157899.asia-east1.run.app/auth ▼ GCP Cloud Run (music-inspect / nginx) │ proxy_pass https://eip.fme.com.tw/FMEIP/AasApi/CheckUserId │ proxy_ssl_server_name on │ proxy_set_header Host eip.fme.com.tw ▼ FME 公司內網 CheckUserId API │ 回傳 { MSG, CODE } ▼ 前端判斷 CODE === '0' → 登入成功 → 狀態存入 sessionStorage（關閉分頁即清除）
ℹ️ 為何需要 GCP Proxy？Cloudflare Workers 的出口 IP 被 FME 公司防火牆封鎖。透過 GCP Cloud Run（固定 IP 段）代理，可正常存取公司內網 API。

XSS 修復（已完成）

在 index.html const API 宣告後新增 esc() 函式：

function esc(s){
  return String(s==null?'':s)
    .replace(/&/g,'&amp;')
    .replace(/</g,'&lt;')
    .replace(/>/g,'&gt;')
    .replace(/"/g,'&quot;')
    .replace(/'/g,'&#39;');
}
