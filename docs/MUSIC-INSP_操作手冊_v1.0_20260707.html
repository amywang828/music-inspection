系統簡介

本系統供日翊文化行銷盤點一部、二部各課別點檢人員，記錄門市音樂置換的點檢狀況。系統整合 FME 企業帳號登入，支援離線 PWA 安裝，並自動同步資料至 Google Sheets 備份。月底可直接產出請款明細報表，計算各課別應收費用。

3. 帳號與登入

3.1 帳號申請

本系統使用 FME 企業帳號（eip.fme.com.tw 的員工帳號）登入，無需另行申請。確認您可以登入公司 EIP 系統即可使用本 APP。

ℹ️ 說明如遇帳號問題，請聯絡公司人資或 IT 部門重設 EIP 帳號密碼。

3.2 登入步驟

  1. 開啟瀏覽器，前往系統網址：https://music-inspection.pages.dev
  2. 輸入 FME 員工帳號（格式：英文字母+數字，如 abc12345）
  3. 輸入 員工密碼（同 EIP 登入密碼）
  4. 點擊「登入」按鈕
  5. 登入成功後自動進入系統主畫面
⚠️ 注意建議使用 Chrome 或 Edge 瀏覽器。關閉瀏覽器後需重新登入（登入狀態不跨瀏覽器 session 保留）。

3.3 忘記密碼

本系統密碼即 FME 企業帳號密碼。如忘記密碼，請聯絡公司 IT 或人資部門重設 EIP 密碼。

3.4 登出

點擊右上角「登出」按鈕即可登出系統。

4.1 基本資料

用途：開始一筆新的點檢記錄，選擇部別、課別、人員、店舖與點檢日期。

操作步驟

  1. 選擇「部別」（盤點一部 / 盤點二部），課別選項會自動連動更新
  2. 選擇「課別」
  3. 選擇「點檢人員」（由維護管理預先設定）
  4. 選擇「店舖」（由維護管理預先設定）
  5. 選擇「點檢日期」（預設為今天）
  6. 點擊「前往點檢問答 →」開始點檢

欄位說明

欄位說明必填
部別盤點一部（北部/桃竹）或盤點二部（中南部）✓
課別依部別連動顯示對應課別✓
點檢人員執行點檢的人員姓名✓
店舖本次點檢的門市名稱✓
點檢日期實際點檢日期（YYYY-MM-DD）✓
⚠️ 同月同店防重複同一課別、同一店舖、同一月份只允許一筆記錄。若已存在記錄，系統會提示衝突，請改用「查詢記錄」功能修改原始記錄。

4.2 點檢問答

用途：逐題回答點檢問題，記錄每題通過或未通過的狀況。

操作步驟

  1. 系統自動載入點檢題目清單（由維護管理設定）
  2. 每題選擇「通過」或「未通過」
  3. 如有題目未通過，可在備註欄填寫原因說明
  4. 確認所有題目填寫完成後，點擊「✔ 提交此筆點檢記錄」
  5. 系統顯示提交成功，記錄即時儲存並同步至 Google Sheets
💡 提示如需修改已提交的記錄，請至「查詢記錄」頁籤找到該筆記錄進行修改。

4.3 查詢記錄

用途：查詢已提交的點檢記錄，支援修改與刪除。

操作步驟

  1. 選擇「課別」及日期範圍（起訖日期）
  2. 點擊「查詢」載入符合條件的記錄清單
  3. 點擊特定記錄可查看詳情
  4. 如需修改：點擊「編輯」按鈕 → 修改內容 → 儲存（系統自動記錄修改人與時間）
  5. 如需刪除：點擊「刪除」→ 輸入密碼 9588 確認 → 記錄永久刪除
⚠️ 刪除需密碼刪除記錄需輸入密碼 9588，刪除後無法復原，請謹慎操作。

頁面統計

查詢結果頁面上方顯示：總點檢筆數、本月筆數、全部通過數量等統計資訊。

4.4 點檢結果（報表與請款）

用途：查看統計報表，並產出音樂置換請款明細（含費用計算）。

① 點檢清單統計

  1. 選擇「課別」與日期範圍
  2. 點擊「查詢」，系統顯示每店最新一筆點檢記錄的彙整清單
  3. 統計欄位包含：店數、通過店數、未通過店數、通過率

② 音樂置換請款明細

  1. 選擇月份與查詢範圍
  2. 點擊查詢，系統依計費規則自動計算
  3. 可選擇「匯出 Excel」下載請款明細表

計費規則

計費項目金額
每店點檢費（一般）NT$ 110 / 店
備註含「1、2、4燈恆亮」的店NT$ 0（免費）
資料彙總費NT$ 8,000 / 月
稅率5%（四捨五入）
ℹ️ 說明請款明細受密碼保護。查看前需輸入密碼 9588。報表取每店該月最新一筆記錄，跨全部課別合計。

4.5 維護管理

用途：管理系統基礎資料，包含應查核店舖、人員名單與點檢題目。

⚠️ 注意維護管理功能僅限具管理權限的人員操作，一般點檢人員請勿任意修改。

4.5.1 應查核店舖管理

操作說明
新增店舖輸入課別、店名，點擊「新增」
刪除店舖點擊店舖旁「刪除」，需輸入密碼 9588 確認

各課別的店舖清單獨立管理，不互相影響。

4.5.2 人員名單管理

操作說明
新增人員輸入課別、姓名，點擊「新增」
刪除人員點擊人員旁「刪除」，需輸入密碼 9588 確認

4.5.3 點檢題目管理

操作說明
新增題目輸入題目文字、通過選項、未通過選項
刪除題目需輸入密碼 9588 確認
調整順序拖拉或上下移動題目排序

4.6 點檢 SOP

用途：查閱音樂置換點檢的標準作業程序，了解各項目的檢查標準。

點擊頂部橘紅色「點檢SOP」頁籤即可查看，內容包含點檢項目說明表格及操作指引。

💡 提示點檢 SOP 頁籤為唯讀，如需更新 SOP 內容請聯絡系統維護人員。

4.7 PWA 安裝（加入手機主畫面）

用途：將 APP 安裝到手機主畫面，像原生 APP 一樣使用，支援離線讀取已快取的資料。

Android 安裝步驟

  1. 使用 Chrome 開啟系統網址
  2. 點擊系統頂部出現的「安裝應用程式」橫幅，或點擊瀏覽器右上角選單
  3. 選擇「新增至主畫面」
  4. 確認後 APP 圖示出現於主畫面

iOS（iPhone）安裝步驟

  1. 使用 Safari 開啟系統網址
  2. 點擊下方分享按鈕（方形＋箭頭圖示）
  3. 選擇「加入主畫面」
  4. 點擊「新增」完成安裝
ℹ️ 離線功能說明安裝後，已查詢過的資料可在無網路狀態下讀取。新增或修改記錄需有網路連線。系統頂部會顯示「線上」或「離線」狀態。

6. 常見問題 FAQ

Q1. 登入時出現「帳號或密碼錯誤」？

→ 請確認帳號為 FME EIP 登入帳號，密碼同 EIP 密碼。如密碼正確仍無法登入，請確認公司 EIP 系統是否能正常登入。如 EIP 也無法登入，請聯絡人資或 IT 部門。

Q2. 提交點檢記錄時出現「同月同店已有記錄」？

→ 表示該課別、該店舖、本月已有一筆記錄。請至「查詢記錄」頁籤找到原始記錄進行修改，不需重新提交。

Q3. 店舖或人員選單是空的？

→ 請確認是否已在「維護管理」頁籤中，依課別新增店舖和人員資料。各課別的資料獨立，請選擇正確課別後再新增。

Q4. 系統顯示「離線」但我有網路？

→ 嘗試重新整理頁面（F5 或下拉重整）。若仍顯示離線，請確認是否能開啟其他網站（確認網路連線正常）。

Q5. 請款明細無法查看？

→ 查看請款明細需輸入管理密碼 9588。如您有此需求但不知道密碼，請聯絡所屬課別負責人。

Q6. 操作時畫面凍結或出現錯誤？

→ 請記下錯誤訊息與發生時間，截圖後回報給系統維護人員。可嘗試重新整理頁面後再操作。

Q7. 手機版操作顯示異常？

→ 建議使用 Chrome（Android）或 Safari（iOS）瀏覽器，並確認使用最新版本。

Q8. Google Sheets 資料沒有更新？

→ Sheets 同步為非同步操作，通常在幾秒內完成。若超過 1 分鐘仍未更新，請回報給系統維護人員確認同步服務狀態。

8. 資料保護說明

本章節說明本系統儲存之資料範圍及保護措施。

8.1 個人資料

欄位所在資料表資料內容儲存方式
name（人員姓名）staff點檢人員姓名明文
staff（點檢人員）records提交點檢記錄的人員姓名明文
⚠️ 注意上述欄位含個人資料，資料庫存取應限縮於系統服務帳號，非相關人員不應直接查詢 D1 資料庫。

8.2 機敏資料

本系統資料庫欄位經掃描，不含人資類（薪資、人力）或財會類（預算、效益金額）機敏資料。請款金額由前端依規則即時計算，不存入資料庫。

8.3 資料保護措施

措施說明
傳輸加密HTTPS（TLS 1.2+），Cloudflare 自動管理憑證
XSS 防護所有 innerHTML 插值經 esc() 函式 HTML 實體逸脫處理
登入速率限制每 IP 每分鐘最多 10 次 /api/auth 請求
CORS 限制Worker API 僅接受 Cloudflare Pages 及 GCP Cloud Run 的請求來源
敏感操作確認刪除記錄、查看請款明細需輸入密碼確認
錯誤訊息保護後端不回傳內部錯誤細節（僅回傳 "Internal server error"）
